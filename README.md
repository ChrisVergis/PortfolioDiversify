# Diversification vs All-In Investing

## Overview

This repository explores a simple but often misunderstood idea in investing:  
**diversifying across multiple assets is not indecision, it is risk management.**

The project compares an all-in investment strategy with diversified portfolios built from assets with imperfect correlations. Using quantitative metrics and visual analysis, it shows how diversification can improve risk-adjusted performance and reduce downside risk without sacrificing expected returns.

## Motivation

Concentrated strategies are frequently associated with conviction, while diversification is sometimes framed as a lack of decisiveness. In financial markets, however, diversification is a standard tool for managing uncertainty. This project applies the same logic to portfolio construction and evaluates when and why diversified strategies outperform all-in approaches.

## What’s Included

- Construction of all-in and diversified portfolios  
- Comparison of expected returns, volatility, Sharpe ratio, and drawdowns  
- Efficient frontier visualization  
- Utility-based performance evaluation  
- Stress testing under adverse market conditions  

The analysis uses either historical market data or simulated returns to clearly isolate the effects of diversification.

## Key Takeaways

- Diversification reduces risk through imperfect asset correlations  
- Many diversified portfolios dominate single-asset strategies on a risk-return basis  
- All-in strategies only outperform under unrealistically strong assumptions about foresight  
- From a utility perspective, diversification is often optimal even when expected returns are similar

## Conclusion

Diversification is not a lack of focus. It is a mathematically grounded response to uncertainty.  
This project demonstrates why, under realistic assumptions, diversified portfolios offer more robust and resilient outcomes than concentrated, all-in investments.
